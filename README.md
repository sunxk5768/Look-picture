# 图观

一款用于 Edge / Chromium 浏览器的网页图片浏览插件，支持沉浸式看图、参考图对比、自定义旋转与镜像翻转。

## 主要功能

- **沉浸式浏览**：全屏看图、缩略图导航、自动轮播及多种缩放模式。
- **参考图对比**：固定任意图片，与当前浏览图片反复切换，方便观察细节差异。
- **自定义旋转**：通过 0–360° 滑块实时调整角度，精度为 0.1°，支持 ±90° 快速旋转。
- **镜像与翻转**：一键水平镜像、垂直翻转，可重置当前图片的调整。
- **简洁工具栏**：透明磨砂界面，配合轻量图标与浅阴影。

## 安装方式

1. 点击本仓库的 **Code → Download ZIP**。
2. 解压到一个固定文件夹。
3. 在 Edge 地址栏输入 `edge://extensions`。
4. 开启「开发人员模式」。
5. 点击「加载解压缩的扩展」，选择包含 `manifest.json` 的文件夹。
6. 刷新需要浏览图片的网页。

如果已安装原版或其他副本，请先停用，避免同时响应。

> 加载后请勿移动或删除插件文件夹。浏览器中的个性化设置不会随文件复制。

## 使用方法

### 图片浏览

点击网页中的图片进入看图界面。

| 操作 | 功能 |
| --- | --- |
| ← / → | 上一张 / 下一张 |
| 鼠标滚轮 | 切换图片；漫画模式下用于缩放 |
| 空格 | 播放 / 暂停自动轮播 |
| Esc | 退出看图 |
| C | 切换图片橱窗 |
| T | 显示 / 隐藏缩略图栏 |

### 参考图对比

1. 打开希望作为参考的图片，按 **R** 固定。
2. 浏览到另一张图片。
3. 反复按 **V**，在两张图片之间切换。

例如：将图片 1 固定为参考图，浏览到图片 3 后，即可在 **1 ↔ 3** 之间反复对比。继续浏览到图片 5，则可对比 **1 ↔ 5**。

- **R**：将当前显示的图片设为参考图；如果它已经是参考图，则取消固定。
- **V**：在参考图与当前浏览图片之间切换。
- **对比图标**：首次点击固定参考图，之后点击切换；右键可重新设置或取消。
- 查看参考图时，左右键仍从原来的浏览位置继续翻图。
- 设置参考图或切换对比时，会暂停自动播放。

### 旋转与翻转

点击工具栏中的旋转图标，打开角度面板：

- 拖动 **0–360°** 滑块实时旋转，步长为 **0.1°**。
- 点击 **−90° / +90°** 快速旋转。
- 点击水平镜像或垂直翻转图标，调整图片方向。
- 点击「重置」，清除当前图片的旋转与翻转。

## 使用说明与限制

- 参考图和每张图片的方向调整仅在本次看图期间保留，退出后清除。
- 旋转与翻转只改变显示效果，不修改原始文件；下载和复制的仍是原图。
- 漫画模式的移动边界仍按旋转前的图片尺寸计算。
- 网页结构、图片加载方式及网站限制可能影响图片识别。
- 当前通过开发人员模式加载，更新需手动替换文件并重新加载扩展。
